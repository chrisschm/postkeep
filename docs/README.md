# Developer Documentation Index

This is the starting point for anyone who wants to work on Postkeep's **code** - contributors and
maintainers. If you want to install or use Postkeep, see the
[user manual in the wiki](https://github.com/chrisschm/postkeep/wiki) instead; nothing here
duplicates it.

## Start here

- [`ARCHITECTURE.md`](ARCHITECTURE.md) - how Postkeep is built and why: the archive as plain files
  on a network share, the safety rules that protect the only copy of the user's mail, how several
  computers work on the same archive at once, translations, and what is implemented so far.
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) - how to set up a development environment, which
  checks a change has to pass, and the project's conventions (languages, translations,
  dependencies, documentation, test data).
- [`../SECURITY.md`](../SECURITY.md) - how to report a security vulnerability (privately, never as
  a public issue).

This index grows with the project: larger topics get their own file in this folder once there is
enough to say about them, and are listed here. `ARCHITECTURE.md` stays the entry point rather than
accumulating everything.

## Auf Deutsch (Kurzfassung)

Ausgangspunkt für alle, die am Code arbeiten wollen (Mitwirkende und Maintainer). Wer Postkeep
installieren oder benutzen möchte, findet das [Handbuch im Wiki](https://github.com/chrisschm/postkeep/wiki) -
hier gibt es keine Doppelungen.

- [`ARCHITECTURE.md`](ARCHITECTURE.md) - Aufbau und Begründungen: Archiv als einzelne Dateien auf
  einem Netzlaufwerk, Sicherheitsregeln für die einzige Kopie der Mails, gleichzeitige Arbeit
  mehrerer Rechner, Übersetzungen, aktueller Umsetzungsstand.
- [`../CONTRIBUTING.md`](../CONTRIBUTING.md) - Entwicklungsumgebung, Pflichtprüfungen vor einem
  Beitrag, Konventionen (Sprachen, Übersetzungen, Abhängigkeiten, Doku, Testdaten).
- [`../SECURITY.md`](../SECURITY.md) - Sicherheitslücken vertraulich melden, nie als öffentliches
  Issue.

Größere Themen bekommen später eigene Dateien in diesem Ordner und werden hier eingetragen.
